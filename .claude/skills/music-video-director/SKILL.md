# Music Video Director

Claude не слышит звук напрямую. Скилл превращает трек в данные (ритм, энергия, части, текст),
и сценарий строится по ним, а не «на глаз».

## Установка (один раз)

```bash
pip install -r .claude/skills/music-video-director/requirements.txt
# нужен ffmpeg в системе (apt install ffmpeg / brew install ffmpeg / winget install ffmpeg)
```

Первый запуск Whisper скачивает модель (~460 МБ для `small`) с huggingface.co.

## Workflow

1. **Анализ трека**
   ```bash
   python .claude/skills/music-video-director/scripts/analyze_audio.py song.mp3 -o song.analysis.json
   ```
   Флаги: `--language uk|ru|en` (точнее, чем автоопределение), `--whisper-model medium` (лучше текст, медленнее),
   `--no-lyrics` (инструментал). Прочитай сводку в консоли, затем JSON целиком.

2. **Проверь анализ.** Метки intro/verse/chorus — эвристика по энергии. Сверь с текстом песни:
   повторяющиеся строки = припев. Если BPM подозрительный (помечено `!`), учитывай половинный/двойной темп.
   Если что-то критично неясно (жанр, артист, стиль), спроси пользователя.

3. **Бриф.** Если пользователь не задал — спроси кнопками (AskUserQuestion): формат (16:9 / 9:16),
   жанр клипа (сюжетный / перформанс / абстрактный / лирик-видео), визуальный стиль, генератор
   (Veo/Flow, Kling, Runway, Sora), есть ли артист в кадре. Не задавай больше 4 вопросов.

4. **Сценарий** → `song.script.json` (схема ниже), по правилам монтажа.

5. **Раскадровка**
   ```bash
   python .claude/skills/music-video-director/scripts/render_storyboard.py song.analysis.json song.script.json -o song.storyboard.html
   ```
   Скрипт проверяет пропуски/наложения сцен. Исправь все `!` и перерендери.

6. **Отдай пользователю**: короткую концепцию, таблицу сцен (время / часть / что в кадре) и путь к HTML.

## Правила монтажа под музыку

- **Склейки только на долях.** Начало/конец каждой сцены — ближайшее значение из `downbeats`
  (сильные доли), внутри быстрых частей допустимы `beats`. Не выдумывай таймкоды.
- **Длина сцены от энергии части:**
  - low: 2–4 такта (≈ `beat_interval × 8…16`), статичные/медленные планы, общие и средние.
  - mid: 1–2 такта, плавная камера (dolly, slider), смена ракурсов.
  - high (припев, дроп): 0.5–1 такт, крупные планы, быстрые движения, вспышки, резкие склейки.
  - Ограничение генераторов: одна сцена ≤ 8 с (Veo/Kling) — длинные части дели на несколько сцен.
- **`peaks`** — главные визуальные события: смена локации, вспышка, вход артиста, слоу-мо → резкий рывок.
- **`drops`** — пауза: затемнение, тишина в кадре, деталь крупно, замедление.
- **Тональность/настроение** (`mood_hint`, `brightness`): минор + тёмный звук → холодная палитра, ночь,
  контраст; мажор + яркий → тёплый свет, день, насыщенные цвета.
- **Текст песни:** визуал иллюстрирует смысл строки метафорой, а не буквально каждое слово.
  Ключевая строка припева — самый сильный кадр клипа.
- **Драматургия:** завязка (intro/первый куплет) → развитие → кульминация на последнем припеве →
  развязка в outro. Повторяющиеся припевы — повторяющийся визуальный мотив с эскалацией.
- **Единство:** один стиль, палитра и персонажи на весь клип; описание персонажа копируй в каждый промпт
  дословно (иначе генератор сменит внешность).

## Промпт для каждой сцены

Пиши на английском (генераторы понимают его лучше), одним абзацем, в порядке:

`[тип плана], [движение камеры]. [Субъект — полное описание персонажа]. [Действие]. [Окружение]. [Свет и палитра]. [Стиль/плёнка/объектив]. [Темп движения под музыку]. [Формат].`

Пример: `Close-up, slow push-in. A young woman with short silver hair, black leather jacket, small scar on left eyebrow. She opens her eyes as neon lights flicker on behind her. Rainy rooftop at night, city skyline. Cold teal and magenta neon, wet reflections. Anamorphic lens, 35mm film grain, shallow depth of field. Movement timed to a slow 76 BPM pulse. 16:9.`

- Kling/Runway: добавляй в конец длительность (`5s`) и избегай текста в кадре.
- Veo/Flow: можно описать звук/атмосферу, но музыку клипа накладывают при монтаже — не проси вокал.
- Если установлены скиллы `flow-banana-director` или `google-flow-video-guide` и пользователь выбрал
  Google Flow — сверяйся с ними по формату промптов.

## Схема `script.json`

```json
{
  "title": "Название трека",
  "artist": "Исполнитель",
  "concept": "2–3 предложения: о чём клип, главный визуальный мотив, развитие.",
  "style": {"format": "16:9", "palette": "teal / magenta neon", "look": "35mm, anamorphic", "generator": "Veo 3"},
  "characters": [{"name": "Героиня", "description": "young woman, short silver hair, black leather jacket"}],
  "scenes": [
    {
      "id": 1,
      "start": 0.0,
      "end": 6.32,
      "section": "intro",
      "shot": "общий план",
      "camera": "медленный наезд",
      "visual": "Крыша в дождь, героиня спиной к камере",
      "lyrics": "",
      "transition": "склейка на сильную долю",
      "prompt": "Wide shot, slow push-in. ..."
    }
  ]
}
```

Требования: сцены идут встык (end одной = start следующей), первая с 0, последняя заканчивается на
`duration`. `section` — одно из intro/verse/chorus/bridge/outro.
